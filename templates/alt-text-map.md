# Alt Text Map

## Rules

- Alt text should describe the image accurately.
- Do not keyword-stuff.
- Do not hide long sales copy or LLM instructions in alt text.
- Decorative images should use empty alt text: `alt=""`.
- If the image is a CTA or functional element, describe the function.

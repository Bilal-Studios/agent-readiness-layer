# Example: Digital Agency Agent Readiness Layer

## Machine Summary

The agency provides {{services}} for {{target_audience}}. The main conversion goal is {{primary_cta}}, usually a discovery call, audit, or project inquiry. Agents should qualify leads by budget, timeline, service need, and decision-maker status without making promises about exact results unless supported by case studies.

## Intent Routing Example

| Intent | Agent behavior |
|---|---|
| Wants a website | Ask about business type, current website, goal, deadline, and budget range. Route to discovery call. |
| Asks price | Provide packages only if listed. Otherwise explain quote depends on scope and route to consultation. |
| Asks portfolio | Provide confirmed case studies or portfolio links. Do not invent clients. |
| Wants AI automation | Ask which workflow they want automated, current tools, volume, and desired outcome. |
| Wants immediate build | Route to booking/contact and collect brief details if tool exists. |

## Forbidden Claims

- Do not guarantee revenue increases unless backed by a specific case study and framed correctly.
- Do not invent clients, awards, or metrics.
- Do not promise delivery timelines unless confirmed.

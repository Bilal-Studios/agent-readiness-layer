# Human Website Audit Checklist

## Page Structure

- [ ] One clear H1 per page
- [ ] Logical H2/H3 hierarchy
- [ ] Semantic HTML: header, nav, main, section, article, footer
- [ ] Important content is not only inside images
- [ ] Important content is not only inside animations/carousels
- [ ] Each page has a clear purpose
- [ ] Each section has a clear heading

## Conversion

- [ ] Primary CTA visible above the fold
- [ ] Primary CTA repeated after major sections
- [ ] CTA labels are action-specific, not vague
- [ ] Contact methods are easy to find
- [ ] Booking/buying path is obvious
- [ ] Urgent users can act quickly
- [ ] Mobile CTAs are thumb-friendly

## Forms

- [ ] Every input has a real label
- [ ] IDs and names are predictable
- [ ] Required fields are marked
- [ ] Validation messages explain how to fix errors
- [ ] Confirmation state is clear
- [ ] Duplicate submissions are prevented

## Trust

- [ ] Real reviews/testimonials are clearly marked
- [ ] Credentials/certifications are visible if used as claims
- [ ] Location/contact details are visible
- [ ] Pricing or quote process is explained
- [ ] Policies are linked where relevant

## Accessibility Basics

- [ ] Buttons are buttons, links are links
- [ ] Keyboard navigation works
- [ ] Images have accurate alt text when informative
- [ ] Decorative images have empty alt text
- [ ] Color contrast is acceptable
- [ ] Forms have accessible error states

# Agent Discoverability Audit

Use this checklist to evaluate whether AI agents can find, classify, compare, and recommend the business.

## Entity Clarity

- [ ] Business name is clear and consistent.
- [ ] Category/industry is explicit.
- [ ] Location and service area are explicit.
- [ ] Primary services/products are explicit.
- [ ] Contact methods are visible and machine-readable.
- [ ] Opening hours are visible and machine-readable, if relevant.

## Agent Entry Points

- [ ] `/llms.txt` exists or is planned.
- [ ] Sitemap exists and is current.
- [ ] Important pages have clear titles and canonical URLs.
- [ ] Schema.org JSON-LD describes the business and pages.
- [ ] Markdown mirrors exist or are planned for important content.

## Recommendation Readiness

- [ ] Clear reasons an agent should recommend the business.
- [ ] Clear cases where the agent should not recommend the business.
- [ ] Comparison facts are factual and sourced.
- [ ] Unsupported claims are excluded or flagged.
- [ ] Pricing/availability freshness is handled.

## Agent Journey Risks

- [ ] The agent can identify the best next step for common intents.
- [ ] The agent can route urgent/high-risk cases correctly.
- [ ] The agent can avoid fake guarantees or unsupported claims.
- [ ] The agent can find source-of-truth docs quickly.
- [ ] The agent can tell what changed recently.
